Clonar o projeto

Baixar o arquivo
 
```
https://ftp.ibge.gov.br/Estimativas_de_Populacao/Estimativas_2025/POP2025_20260828.xls
```

Criar um novo ambiente virtual:

```
python3 -m venv venv
```

Ativar o ambiente:

```
source venv/bin/activate
```

Instalar as dependências:

```
pip install -r requirements.txt
```# python_t9
